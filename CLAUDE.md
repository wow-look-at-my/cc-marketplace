## No Overwrites Plugin

The `no-overwrites` plugin (`plugins/no-overwrites/hook.sh`) is the other half of the cleanup-bash-cmds plugin (see `plugins/cleanup-bash-cmds/CLAUDE.md`): it blocks `Write` on a path that already exists (use `Edit`), and -- because delete-then-`Write` is the loophole around that block -- ALSO blocks `Write` on a path that does not exist but IS in the recycle bin, naming `recycler restore <path>` so the bytes are recovered instead of re-authored from context. It matches the target against `recycler list --json` `.original_path`, comparing both the literal path and the physically-resolved one (macOS records `/tmp/x` as `/private/tmp/x`). It keeps no ledger of its own -- recycler already tracks original locations -- and any failure (no recycler, unreadable bin, no match) falls through to allow.
