## Glob Plugin

The glob plugin lives at `plugins/glob/`. Engine: ripgrep (`rg --files --glob <pat> --no-ignore --hidden`, so `.gitignore` is NOT respected and dotfiles/`.git` ARE listed -> env-overridable via `CLAUDE_CODE_GLOB_NO_IGNORE`/`CLAUDE_CODE_GLOB_HIDDEN`), oldest-first mtime order **sorted in Go, not via `--sort=modified`** (identical order on rg 13/14/15 -- rg 13 sorted per-directory. Ties break by the localeCompare collator in `collate.go`), and a `25000`-file cap with the verbatim truncation line. It has a `20s` (`60s` WSL) timeout via `CLAUDE_CODE_GLOB_TIMEOUT_SECONDS`, and a `>50000`-char persist-to-temp-file. The `path` argument gets the builtin's Vq preprocessing (whitespace trim, `~`/`~/x` home expansion, null-byte rejection) plus one amendment: the literal strings `"undefined"`/`"null"` resolve to the root instead of erroring. JSON `null` pattern/path are rejected at -32602. Ripgrep exit 2 with no output (invalid glob) surfaces rg's stderr as a tool error capped at multiple chars -- same deliberate deviation as grep. Requires `rg` (13.0.0+) on PATH (or `RIPGREP_PATH`). A missing ripgrep is a tool error. The MCP tool is `Glob` on server key `glob`, so the model-visible name is `mcp__plugin_glob_glob__Glob`. `.mcp.json` sets `alwaysLoad: true` so the tool is never deferred behind ToolSearch. A version gate hides the tool from `claude-code` clients whose version parses as < 2.1.117 (they still have the builtin). Override with `CC_GLOB_PLUGIN=always|never|auto`.

- **Tool logic**: `plugins/glob/globtool.go` -- description const, typed schema structs, rg argv, validation, Go-side mtime sort, result formatting
- **Protocol / gate / runner / persist / collation**: the shared `tools/rgmcp` module, compiled in through a local `replace` in `go.mod`. `main.go` names the gate variable. A change there rebuilds both glob and grep
- **Tests**: `plugins/glob/*_test.go` cover the tool. The protocol and gate tests live in `tools/rgmcp`. `rgmcp/testkit` bootstraps a pinned ripgrep 14.1.0 when the machine lacks one (CI runners). The suite passes against rg 13.0.0, 14.1.0, and 15.1.0
