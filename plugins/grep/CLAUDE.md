## Grep Plugin

The grep plugin lives at `plugins/grep/`. The builtin's `--max-columns 500` line omission is dropped so a matching line is never lost. Context precedence `context` > `-C` > `-B`/`-A`. `-e` for dash-leading patterns. Zod-style input coercions. Vq path preprocessing -- whitespace trim, `~`/`~/x` home expansion, null-byte rejection, plus the same `"undefined"`/`"null"`-resolve-to-root amendment as glob. Q46/l46 pagination with the exact result strings. Newest-first mtime sort with the builtin's localeCompare tie-break ported in `collate.go` via x/text ICU root collation. Output modes documented solely on the `output_mode` property), the builtin's ambiguous `type` parameter is REMOVED (unknown-argument error. `glob` covers filtering), and `output_mode` is exactly `content` | `filenames_with_matches` | `filenames` | `count` -- the old `files_with_matches` name is gone, no alias. `filenames` returns exactly what the old `files_with_matches` returned. `content` is byte-parity. `count` adds the upstream `-c -H` single-file fix. Ripgrep exit 2 with no output (invalid regex/glob/type) surfaces rg's stderr as a tool error (capped at 4000 chars) instead of the builtin's silent "No matches found". Requires `rg` (13.0.0+) on PATH (or `RIPGREP_PATH`). Model-visible name: `mcp__plugin_grep_grep__Grep` (`alwaysLoad: true`). Version gate: hidden for `claude-code` < 2.1.117. Override `CC_GREP_PLUGIN=always|never|auto`.

- **Tool core**: `plugins/grep/greptool.go` -- description/schema consts, typed schema structs, argument parsing/coercions, rg argv, path validation
- **Mode formatting**: `plugins/grep/grepmodes.go` (content/count/filenames + Q46/l46 ports), `plugins/grep/grepfwm.go` (the grouped default mode over rg --json), `plugins/grep/clamp.go` (the shared long-line clamp/window that replaced `--max-columns 500`)
- **Protocol / gate / runner / persist / collation**: `plugins/grep/server.go`, `gate.go`, `rg.go` (carries the exit-2 stderr deviation, shared verbatim with glob), `persist.go`, `paths.go`, `collate.go`
- **Tests**: `plugins/grep/*_test.go` -- byte-exact goldens for every output mode, same ripgrep bootstrap as glob. Suite passes against rg 13.0.0, 14.1.0, and 15.1.0 on Linux (two known macOS-only environmental failures: symlinked-search-path globs and binary-file line rendering)
